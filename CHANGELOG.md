# Changelog

## Unreleased

### Added
- `Faker.RefDate`: the reference "now" for date generators. With a fixed seed and
  `RefDate`, dates are reproducible too (they used to depend on the current time).

### Fixed
- Locale `ua` now applies to people, not only addresses: Ukrainian first and last
  names, `+380` phone numbers, `буд.` in streets and 5-digit zip codes
  (it used to return English names and 6-digit codes).
- Transliteration handles Ukrainian letters `і ї є ґ` and the apostrophe, so emails
  and usernames stay ASCII for every locale.
- `FillStruct` no longer panics on an embedded `*Struct` (filled when not nil) or an
  embedded non-struct type (skipped without a tag, filled with one).
- `FillSlice` supports `[]*T` instead of panicking, and returns an error for slices of
  non-structs; a negative `n` yields an empty slice.
- `PickOne` panics with a clear message on an empty slice instead of an index error.
- Removed a stray `func main()` from the library package.

### Changed
- The package is installed with gtr: `gtr.json` replaces `go.mod` (generated by gtr, not
  committed), and packages of the family are imported by their gtr names (`import "orm"`,
  `"orm/schema"`, `"orm-postgres"`, `"passport"`, …) instead of `github.com/shibisty/...`
  paths (ADR-0001, ADR-0002). Packages that plug into a core list it as a peer dependency.
  CI builds gtr-manager from source and runs `gtr install`.
- Minimum Go version is 1.22 (was 1.26.5 in go.mod, 1.18 in README).
- Locale data lives in one table (`locale.go`); `"uk"` is accepted as an alias of `"ua"`.
  Output for `en` and `ru` with the same seed is unchanged.
- Documentation: methods are safe for concurrent use (they always were); README lists
  only the API that exists and the full set of struct tags.

### Added
- `faker.Locales()`.
- Tests for every generator, locale, struct tag and type conversion; a fuzz test for tag
  parsing; coverage 98.6%.
- GitHub Actions CI: Linux, Windows, macOS × Go 1.22 and stable, `-race`, coverage gate
  85%, staticcheck, short fuzzing.
